# NorthFlow — Screen Architecture & UX Responsibilities

# Purpose of This File

This file defines:
- every core screen
- its emotional purpose
- responsibilities
- UX behavior
- interaction philosophy
- what should and should NOT exist on the screen

This document helps:
- frontend developers
- AI design agents
- product designers
- future contributors

maintain consistency across the product.

---

# Global Screen Principles

Every screen in NorthFlow should:
- reduce mental noise
- preserve emotional calm
- avoid dashboard overload
- feel typography-first
- support reflection
- feel emotionally intelligent
- maintain visual breathing room

The product should NEVER feel:
- corporate
- KPI-heavy
- gamified
- hustle-oriented
- motivational
- productivity obsessive

---

# Navigation Structure

Bottom navigation tabs:

1. Today
2. Week
3. Goal
4. Settings

Important:
Today is the emotional home of the product.

---

# 1. Today Dashboard

## Core Purpose

The Today Dashboard is the emotional center of NorthFlow.

This screen should help users feel:
- grounded
- calmer
- clear about today
- aware of meaningful progress

This screen is NOT:
- a task manager
- a KPI dashboard
- a productivity center

It IS:
> a personal engineering clarity workspace.

---

# Responsibilities

The Today screen has ONLY 4 jobs:

1. Remind what matters
2. Capture meaningful work quickly
3. Show progress calmly
4. Encourage reflection

Nothing else.

---

# Main Components

## Header
Purpose:
orientation and emotional grounding.

Contains:
- greeting
- profile
- minimal actions

---

## Current North Star Goal
Purpose:
show long-term direction.

Only ONE active goal shown.

This should feel:
identity-oriented.

NOT project-oriented.

---

## Needle-Mover
Purpose:
help users focus on ONE meaningful thing today.

Question:
“What would make today feel meaningful?”

---

## Quick Add Input
Purpose:
ultra-fast logging.

This is the retention engine of the app.

Should feel:
- invisible
- lightweight
- native-like

---

## Timeline
Purpose:
create visible memory of the day.

Timeline should feel:
- reflective
- calm
- breathable

NOT:
- structured task feed
- activity dashboard

---

## Reflection Prompt
Purpose:
create emotional closure.

Examples:
- “How did today feel?”
- “Ready to reflect on today?”

This is a core product differentiator.

---

## Mini Insight Footer
Purpose:
provide subtle AI-like awareness.

Examples:
- “Today was mostly goal-aligned.”
- “Learning took most of your focus today.”

---

# Empty State

Example:

“No pressure.
Start by logging one thing you worked on today.”

Tone should feel:
- human
- calm
- non-corporate

---

# 2. Goal Setup Screen

## Purpose

Help users choose one meaningful direction.

This screen defines the emotional relationship with the app.

It should feel:
- reflective
- calm
- intentional

NOT:
- motivational
- self-help oriented
- challenge-based

---

# Responsibilities

- create north-star goal
- reduce mental fragmentation
- reinforce focus philosophy
- guide intentional direction

---

# Important Philosophy

NorthFlow goals are:
identity directions.

NOT:
project tasks.

Examples:
- Become Senior Backend Engineer
- Ship My First SaaS
- Improve Deep Work Consistency

---

# UX Rules

Avoid:
- streaks
- challenge language
- commitment counters
- motivational framing
- SMART-goal corporate feeling

Use:
- reflective prompts
- calm language
- gentle guidance

---

# Important Product Rule

Only ONE active goal at a time.

This reinforces:
clarity through reduction.

---

# 3. Goal Management Screen

## Purpose

Help users manage long-term personal direction.

This screen should feel like:
> a personal evolution archive.

---

# Responsibilities

- active north-star goal
- future goals
- paused goals
- completed goals
- archived goals
- personal growth timeline

---

# Emotional Goal

“I can clearly see how I’ve evolved.”

## Future Goals
Aspirational parking lot.

## Paused Goals
“Not now” — not failure.

## Completed Goals
Meaningful identity reinforcement.

## Archived Goals
Past life seasons.

---

# Goal Timeline

Should feel:
- editorial
- reflective
- calm

NOT:
activity history.
